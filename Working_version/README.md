# Холтер: запись на microSD и приём CSV

Учебный приёмник сигнала AD8232 на XIAO ESP32-C3. График показывает записанный сигнал и не заменяет медицинское заключение.

Пока идёт запись, контроллер пишет CSV на карту и не подключается к сети. Удержание кнопки 3 секунды ищет Wi-Fi и отправляет файлы на ноутбук в той же сети.

```text
firmware/   прошивка PlatformIO
server/     приём CSV, история, просмотр
server/data принятые файлы
```

## Распиновка

| Сигнал | XIAO ESP32-C3 |
| --- | --- |
| AD8232 OUTPUT | D0 |
| AD8232 3.3V, GND | 3V3, GND |
| Кнопка (второй контакт на GND) | D1 |
| microSD CS | D2 |
| microSD SCK, MISO, MOSI | D8, D9, D10 |

Модуль карты со своим стабилизатором питается от пина 5V. Модуль только на 3,3 В — от пина 3V3. GND общий у XIAO, AD8232 и карты.

SDN у AD8232 оставьте свободным или подтяните к 3,3 В. Электроды: RA, LA, RL.

D9 — контакт загрузки. Если прошивка не стартует, выньте карту, прошейте плату и вставьте карту снова.

## Кнопка D1

Кнопка замыкает D1 на GND.

- Двойное нажатие в простое открывает новый `/ecg_0001.csv` и пишет отсчёты с частотой 50 Гц.
- Двойное нажатие во время записи закрывает файл.
- Удержание 3 секунды закрывает файл, если запись шла, подключает Wi-Fi и отправляет все CSV без метки `.sent`. После ответа сервера на карте появляется пустой `ecg_0001.csv.sent`.
- Одиночное нажатие ничего не делает.

В CSV нет часов реального времени, только миллисекунды от начала сессии:

```csv
t_ms,ecg
0,2048
20,2055
```

## Прошивка

В `firmware/include/config.h` укажите сеть, IP ноутбука, имя пациента и токен. Токен должен совпадать с сервером.

```bash
cd firmware
pio run -t upload
pio device monitor
```

Плата: `seeed_xiao_esp32c3`.

## Сервер

PostgreSQL 18 уже стоит на этой системе. Кластер нужно запустить и один раз завести пользователя базы:

```bash
sudo systemctl start postgresql
sudo systemctl enable postgresql
sudo -u postgres createuser --superuser "$USER"
sudo -u postgres createdb -O "$USER" ecg
```

Дальше, из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r server/requirements.txt
export DEVICE_TOKEN=change-me
export DATABASE_URL=postgresql:///ecg
uvicorn app:app --app-dir server --host 0.0.0.0 --port 8000
```

IP ноутбука для `SERVER_HOST`: `ip -4 addr`. Адрес в прошивке выглядит как `http://192.168.x.x:8000`, порт задаётся отдельно.

Страницы:

- `/` — история из PostgreSQL
- `/files` — CSV из папки `server/data`, имя пациента в имени файла
- `/recordings/{id}` — вся запись прореженной лентой и окнами по 10 секунд, кнопка скачивает исходный CSV

Отсчёты в базу не пишутся. Если база недоступна в момент приёма, файл на диск не остаётся, и контроллер повторит отправку при следующем удержании.
